HOW IT WAS MADE (environment: Linux cloud container, CPU only, FFmpeg 6, Python 3.13)
1. Facts: verified on koenigsegg.com plus press coverage (documentation/factual_sources.txt).
2. Footage: no licensed motion footage of the Jesko Absolut exists that can be reused, and no
   video-generation API was configured. So the visuals are genuine Wikimedia Commons photographs, cut
   out with BiRefNet, composited into a dark studio with a floor reflection taken from the car itself,
   graded, and animated with camera moves, light sweeps, engine-synced shake, airflow lines and speed
   streaks. No AI-generated car imagery, and no fake driving footage.
3. Voice: Kokoro-82M TTS (am_michael 60% + am_fenrir 40%, speed 0.92), with phoneme overrides for
   KER-nig-seg / YES-ko / AB-so-loot; EQ, compression, short room reflection. Whisper transcription of
   every line matched the script.
4. Music and SFX: synthesized in NumPy (project/editing_project_files/music.py, sfx.py, engine.py).
5. Render: render.py writes frames into FFmpeg (libx264); the master audio was loudness-normalized in two
   passes.

Rebuild: cd project/editing_project_files; make_vo.py -> mix.py -> music.py / sfx.py -> master.py ->
cutout.py / plates.py -> render.py (paths inside the scripts assume the original working folders).

====================================================================================================
LIMITATIONS AND WHAT WOULD RAISE THE CEILING
- Real motion footage: the brief prefers genuine licensed video. None is publicly licensed for reuse.
  Options: license clips from Koenigsegg's press office (media.koenigsegg.com) or a stock agency; or set up
  a video-generation API (e.g. Runway, Google Veo, Kling) with the credentials as environment secrets.
  AI driving shots would have to be labeled as AI-generated.
- Authentic engine audio: the engine is a physically informed synthesis, not a Jesko recording. A
  licensed Jesko recording (Koenigsegg press kit, or a sound library with commercial rights) could drop
  straight into assets/audio_stems/engine.flac.
- Premium human-quality voice: an ElevenLabs (or similar) API key would allow a higher-end narrator;
  re-run mix.py/master.py with the new lines.
- No true rear three-quarter photo was available (the two remaining Commons files were rate-limited), so
  the finale uses the long-tail side profile.
